# TABRIZIAU — Modern Fashion Store

A responsive demo storefront for **TABRIZIAU**, featuring dedicated departments for **Men, Women, Boys and Girls**.

## Included

- 32 featured fashion products across 4 departments
- Real U.S. retail-reference prices checked September 29, 2026
- Representative editorial fashion photography using free Unsplash image links
- Responsive desktop/mobile layout
- Category filters and live search
- Add-to-bag interaction and cart counter
- Customer support and style advisory sections
- Newsletter interaction
- TABRIZIAU logo included locally in `/assets`

## Run locally

Open `index.html` in a browser. Internet access is required for Google Fonts and the linked Unsplash product photography. The layout includes visual fallbacks if remote images are unavailable.

## Important price note

Retail prices can change without notice. See `data/SOURCES.md` for the public price-reference pages used when building this demo.
